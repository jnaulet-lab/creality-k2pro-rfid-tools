# Contributing / Contribuer

## English
Thanks for helping! This project documents a setup tested on a **Creality K2 Pro Combo (CFS)**. Reports from other setups are very welcome.

- **Open an issue** to report a problem or share a result. Please include: printer model, firmware version, Home Assistant / Spoolman / SpoolmanSync / `ha_creality_ws` versions (if you use Part 2), and what you tried.
- **Pull requests** are welcome for fixes, clarifications, translations and new filament examples. Keep the French and English READMEs in sync.
- **Never include secrets**: webhook tokens, passwords you changed, public IP addresses. Use `secrets.yaml` and placeholders.
- **Do not upload a full copy** of the Creality catalog (`material_database.json`). Share small examples only.
- Remember that root access and catalog edits are done at your own risk: describe risks and backups in anything you add.

## Français
Merci de contribuer ! Ce projet documente une installation testée sur une **Creality K2 Pro Combo (CFS)**. Les retours d'autres configurations sont les bienvenus.

- **Ouvre une issue** pour signaler un problème ou partager un résultat. Indique : modèle d'imprimante, version du firmware, versions de Home Assistant / Spoolman / SpoolmanSync / `ha_creality_ws` (si tu utilises la Partie 2) et ce que tu as essayé.
- Les **pull requests** sont bienvenues pour des corrections, précisions, traductions et nouveaux exemples de filaments. Garde les README français et anglais synchronisés.
- **Ne publie jamais de secrets** : tokens de webhook, mots de passe modifiés, adresses IP publiques. Utilise `secrets.yaml` et des valeurs d'exemple.
- **Ne téléverse pas de copie complète** du catalogue Creality (`material_database.json`). Partage seulement de petits exemples.
- Rappelle que l'accès root et la modification du catalogue se font à tes risques : décris les risques et les sauvegardes dans tout ajout.
