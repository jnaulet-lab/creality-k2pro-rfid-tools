# 3D models / Modèles 3D

Each model is provided in `.3mf` and `.stl` formats. / Chaque modèle est fourni aux formats `.3mf` et `.stl`.

| Model / Modèle | Use / Usage |
|---|---|
| [`RFID_Positioning_Tool`](RFID_Positioning_Tool/) | **EN:** Positioning jig for sticking a tag on each flank of a reusable spool.<br>**FR :** Gabarit de positionnement pour coller un tag sur chaque flanc d'une bobine réutilisable. |
| [`RFID_Holder`](RFID_Holder/) | **EN:** Simple holder to place on one flank of a cardboard spool, for use on the external spool holder.<br>**FR :** Support simple à poser sur un flanc d'une bobine carton, pour le support de bobine extérieur. |
| [`Support_RFID_55mm`](Support_RFID_55mm/) | **EN:** Clip-on support for disposable or cardboard spools (55 mm diameter), eSun type.<br>**FR :** Support clipable pour bobines jetables ou carton (diamètre 55 mm), type eSun. |
